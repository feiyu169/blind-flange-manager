# 安全审查专项清单

## 概述

在代码审查后，进行独立的安全审查。安全审查应该是"持续的"，而不是"一次性的"。

## 安全审查阶段

1. 设计阶段：安全设计评审
2. 实施阶段：安全编码检查
3. 发布前：安全扫描
4. 运行时：安全监控

## 安全审查清单

### 认证安全

| 检查项 | 检查内容 | 阻断条件 |
|--------|----------|----------|
| JWT 过期验证 | 是否验证令牌过期时间 | 未验证 = 阻断 |
| 令牌吊销机制 | 是否支持令牌吊销 | 无机制 = 阻断 |
| 密码强度检查 | 是否检查密码复杂度 | 无检查 = 警告 |
| 登录失败限制 | 是否限制登录失败次数 | 无限制 = 警告 |

### 授权安全

| 检查项 | 检查内容 | 阻断条件 |
|--------|----------|----------|
| 角色权限检查 | 是否检查用户角色 | 缺失 = 阻断 |
| 资源权限检查 | 是否检查资源所有权 | 缺失 = 阻断 |
| API 权限检查 | 是否检查 API 访问权限 | 缺失 = 阻断 |

### 数据安全

| 检查项 | 检查内容 | 阻断条件 |
|--------|----------|----------|
| SQL 注入防护 | 是否使用参数化查询 | 无防护 = 阻断 |
| XSS 防护 | 是否转义用户输入 | 无防护 = 阻断 |
| 敏感信息加密 | 是否加密敏感信息 | 明文存储 = 阻断 |

### 配置安全

| 检查项 | 检查内容 | 阻断条件 |
|--------|----------|----------|
| 密钥管理 | 是否安全存储密钥 | 硬编码 = 阻断 |
| HTTPS 强制 | 是否强制 HTTPS | 未强制 = 警告 |
| CORS 配置 | 是否正确配置 CORS | 过宽 = 警告 |

### 接口安全

| 检查项 | 检查内容 | 阻断条件 |
|--------|----------|----------|
| 速率限制 | 是否限制请求频率 | 无限制 = 警告 |
| 输入验证 | 是否验证输入数据 | 无验证 = 阻断 |
| 输出编码 | 是否编码输出数据 | 无编码 = 警告 |
