# 预检阶段检查清单

## 概述

在需求确认后、计划制定前，进行轻量级技术可行性快速检查（30分钟）。

## 检查清单

### 1. 技术栈兼容性（5分钟）

- [ ] 框架版本兼容性检查
- [ ] 库版本兼容性检查
- [ ] 语言版本兼容性检查
- [ ] 操作系统兼容性检查

### 2. 依赖库版本（5分钟）

- [ ] 检查依赖库是否有已知漏洞
- [ ] 检查依赖库是否活跃维护
- [ ] 检查依赖库是否有替代方案

### 3. 安全基线（10分钟）

- [ ] 认证方案检查
- [ ] 密钥管理检查
- [ ] HTTPS 检查

### 4. 架构约束（10分钟）

- [ ] 数据库选型检查
- [ ] 中间件选型检查
- [ ] 部署环境检查

## 阻断条件

以下情况必须阻断，不能进入计划阶段：

1. **P0 安全问题**：硬编码密钥、无认证方案、无 HTTPS 支持
2. **P0 架构问题**：数据库选型不明确、中间件选型不明确、部署环境不明确
3. **P0 依赖问题**：依赖库有已知高危漏洞、依赖库已停止维护
